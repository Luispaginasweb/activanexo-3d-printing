# ActivaNexo - Demo de Impresión 3D

Landing page creada con Vite + React + TypeScript + Tailwind CSS.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

Los recursos multimedia están en `public/assets/`.

Antes de publicar, reemplaza `591XXXXXXXX` en `src/App.tsx` por el número real de WhatsApp.
